# Font Awesome Configuration

Detected by the Font Awesome agent tools. Commit this file so the whole team benefits.

## Integration

- **Method:** Web Fonts + CSS via CDN (cdnjs), class-based `<i>` elements
- **Version:** 7.3.1
- **License:** Free
- **CDN URL:** https://cdnjs.cloudflare.com/ajax/libs/font-awesome/7.3.1/css/all.min.css
- **Families:** classic

## Defaults

- **Style:** solid
- **Family:** classic

## Import Pattern

- No build step — the stylesheet is linked from `index.html` with the same tag and SRI hash the Content Desk uses (`~/code/erc-content-desk/index.html`).
- Icons are created in JS as `<i class="fa-solid fa-{name}" aria-hidden="true"></i>` via `faIcon(name, extraClass)` in `js/app.js`.

## Conventions

- Matches the Content Desk (`erc-content-desk/.font-awesome.md`): same version, same CDN tag, solid classic, `aria-hidden="true"` on every icon, meaning carried by adjacent text.
- The landing page's four section cards keep Kate's own icon set (`assets/home-icons/*.svg`, drawn via CSS mask), and the Texas headline pill keeps her Texas outline (`assets/icons/texas.svg`, an `{svg}` value in `CAT_ICONS`). Everything else is Font Awesome.
- Never a raw text glyph (↗ ← ✓ ×) where an icon belongs — they fall back to Arial.
- Category tag icons (`CAT_ICONS` in `js/app.js`) are keyed by lowercase subtype and take the pill's colour through `currentColor`.
- Medium icons (`MEDIA` in `js/app.js`) ride after the source name on headline rows.
- In-use names: `bullhorn`, `lightbulb`, `sack-dollar`, `star`, `building-columns`, `location-dot`, `video`, `file-circle-check`, `file-lines`, `file-pen`, `flag-usa`, `flag`, `globe`, `book-open`, `newspaper`, `radio`, `tv`, `comment`, `blog`, `house`, `magnifying-glass`, `bars`, `chevron-down`, `envelope`, `arrow-up-right-from-square`, `arrow-left`.
